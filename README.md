# Hermes Transportation Platform

**Courier Services Management and Tracking Platform**

Hermes is a web-based parcel management system for recording and tracking parcels received from couriers, managing courier information, notifying recipients, and generating financial reports.

## Overview

The Hermes Transportation Platform supports the day-to-day handling of parcels held for collection. Staff can record parcel details, associate parcels with couriers, review collection status, and use notifications and financial reports to support operations.

The repository contains a Laravel application with a React-based frontend built using Vite. The project includes database migrations and seeders for setting up a development database and sample data.

## Features

- **Authentication and role-based access:** Sign in to the platform with access determined by the account's role.
- **Parcel management:** Create, search, view, edit, and delete parcel records.
- **Barcode support:** Enter tracking numbers manually, use a device camera to scan a barcode, or use a compatible USB barcode scanner.
- **Courier management:** Maintain courier details and view parcels associated with couriers.
- **Notifications:** Review parcel-related notifications and message history. Recipient contact details can be used for automated messages.
- **Dashboard:** View parcel summaries, collection information, a parcel activity graph, and recently added parcels.
- **Financial reports:** Review parcel revenue over daily, monthly, quarterly, bi-annual, annual, or custom date ranges, and export reports as PDF files.
- **Staff administration:** Manage staff accounts and assign administrator or standard-staff roles.
- **Settings:** Update account details and password, configure company details and parcel numbering, and change the application's appearance.

## Technology Stack

The repository and installation documentation identify the following core tools and technologies:

- **Backend and application framework:** PHP 8.2 and Laravel
- **Frontend:** React, Inertia.js, and Vite
- **JavaScript tooling:** Node.js 18 or later and npm
- **PHP dependency management:** Composer
- **Database:** SQLite is included in the repository; PHP's SQLite extensions must be enabled for the documented setup
- **Version control:** Git

## Prerequisites

Install the following software before setting up the project:

| Software | Version / requirement | Purpose |
| --- | --- | --- |
| PHP | 8.2 recommended | Runs the Laravel application |
| Composer | Latest available version | Installs PHP dependencies |
| Node.js and npm | Node.js 18 or later | Installs frontend dependencies and runs Vite |
| Git | Latest available version | Clones and manages the repository |
| XAMPP | Latest available version | Provides the PHP installation used by the installation guide |
| Visual Studio Code | Latest available version (recommended) | Editing configuration and source files |

The supplied installation guide assumes **Windows 11**. Other operating systems may work, but their setup steps are not covered by that guide.

### PHP configuration

In the `php.ini` file used by your PHP installation, ensure the following extensions are enabled. If an extension line begins with a semicolon (`;`), remove the semicolon and save the file.

```ini
extension=fileinfo
extension=pdo_sqlite
extension=sqlite3
extension=gd
extension=mbstring
extension=openssl
extension=curl
extension=zip
```

The PHP executable used by your terminal and Composer should be the intended installation. Restart terminal sessions after changing PHP configuration.

> **Path note:** The original project README recommends installing the repository in a folder path without spaces or special characters.

## Installation and Setup

The following steps summarise the supplied Installation Guide. Refer to that guide for the illustrated Windows installer and configuration instructions.

### 1. Clone the repository

Open Git Bash in the directory where you want to store the project, then run:

```bash
git clone https://github.com/JandreBurger/Hermes_Platform.git
cd Hermes_Platform
git checkout development
```

### 2. Install dependencies

From the project root, run:

```bash
composer install
npm install
```

### 3. Configure the environment

Create a local environment file from the example:

```bash
cp .env.example .env
```

Then generate the Laravel application key:

```bash
php artisan key:generate
```

Review `.env` and confirm that the application environment and database settings match your local setup. Do not commit local secrets or credentials.

### 4. Prepare the database

For a fresh development database with sample data, run:

```bash
php artisan migrate:fresh --seed
```

**Warning:** `migrate:fresh` drops existing database tables before recreating them. Use it only when you are comfortable losing the current data, such as during an initial development setup.

The repository includes database migrations and seeders for the application's data. Confirm that the SQLite database configuration is correct before running migrations.

## Running the Application

Run the backend and frontend development servers in **two separate terminals**, with both terminals opened in the project root.

**Terminal 1 — Laravel application:**

```bash
php artisan serve --port=8000
```

**Terminal 2 — Vite frontend:**

```bash
npm run dev
```

Keep both terminals running while using the application. Open the local address reported by Laravel in your browser. If Laravel reports a different address or port, use the address shown in the terminal.

## User Access and Roles

The platform supports two account roles:

- **Administrator:** Has access to the administrative areas, including parcels, couriers, notifications, financial reports, and staff management.
- **Standard staff:** Has access to the parcels and notifications areas.

The User Guide describes the application's pages and workflows. It also documents a default administrator account for the demonstration setup. Use those demonstration credentials only in a local test environment, and change default credentials before using the system with real data.
